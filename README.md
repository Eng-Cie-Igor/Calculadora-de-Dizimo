Calculadora de Dízimo

Funcionalidades
Máscara Monetária Automática: Formatação em tempo real no padrão brasileiro (`R$ 0.000,00`), tratando as entradas como centavos.
Cálculo de Porcentagem: Cálculo automático do Dízimo (10%)
Interface Dinâmica: Alternância de etapas (Pergunta e Resultado) com animações em CSS.

Projeto desenvolvido para o portfólio de estudos do curso de Computação.
